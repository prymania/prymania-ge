คอมพิวเตอร์พื้นฐานแบบเข้าใจง่าย

คอมพิวเตอร์ (รวมถึงมือถือและแท็บเล็ต) ทำงานเป็นวงจร รับข้อมูล → ประมวลผล → แสดงผล → เก็บ

ส่วนประกอบเปรียบเหมือนตัวอย่าง
CPU หน่วยประมวลผลสมอง คิดและคำนวณIntel Core, AMD Ryzen, Apple M, Snapdragon
RAM หน่วยความจำหลักโต๊ะทำงาน ยิ่งใหญ่ยิ่งเปิดหลายงานพร้อมกันได้ (ปิดเครื่องแล้วหาย)8 GB, 16 GB
Storage หน่วยเก็บข้อมูลตู้เก็บเอกสาร ปิดเครื่องแล้วข้อมูลยังอยู่SSD, HDD, เมมโมรี่การ์ด
Input / Outputประสาทสัมผัสและปากคีย์บอร์ด ไมค์ กล้อง / จอ ลำโพง
OS ระบบปฏิบัติการผู้จัดการที่สั่งงานทุกส่วนWindows, macOS, Android, iOS, ChromeOS
📏 หน่วยของข้อมูล (จำแค่นี้พอ)

8 bit = 1 Byte · 1 KB ≈ 1,000 Byte · 1 MB ≈ 1,000 KB · 1 GB ≈ 1,000 MB · 1 TB ≈ 1,000 GB

เทียบให้เห็นภาพ: ข้อความแชต ≈ ไม่กี่ KB · รูปจากมือถือ ≈ 2–5 MB · คลิป 1 นาที (Full HD) ≈ 100+ MB

มือถือแจ้งว่า “พื้นที่จัดเก็บเต็ม” ทั้งที่ลบรูปไปแล้วหลายสิบรูป นิสิตคิดว่าตัวการน่าจะเป็นอะไร และควรเช็กตรงไหน?
  • รูปไม่กี่สิบรูปรวมกันแค่ไม่กี่ร้อย MB ตัวการใหญ่มักเป็น วิดีโอ และ ไฟล์ในแอปแชต (LINE/Messenger เก็บรูปและคลิปที่เพื่อนส่งมาไว้ด้วย)
  • เช็กที่ การตั้งค่า → พื้นที่จัดเก็บ (Storage) จะเห็นว่าแอปไหนกินที่มากที่สุด
  • รูปที่ “ลบ” แล้วอาจยังอยู่ในอัลบั้ม ลบล่าสุด / ถังขยะ อีก 30 วัน
  • ทางแก้ระยะยาว: สำรองรูปขึ้นคลาวด์ (Google Photos/Drive) แล้วค่อยลบในเครื่อง

Web Browser ใช้ให้คล่อง

Web Browser คือโปรแกรมที่ใช้เปิดเว็บ เช่น Chrome, Edge, Safari, Firefox ทุกตัวมีหน้าตาคล้ายกัน

ส่วนใช้ทำอะไร
Address bar (แถบที่อยู่)พิมพ์ URL หรือคำค้นได้เลย · ดูรูปกุญแจ/คำว่า https:// ก่อนกรอกรหัสผ่าน
แท็บ (Tab)เปิดหลายเว็บในหน้าต่างเดียว · Ctrl+T เปิดใหม่ · Ctrl+Shift+T เปิดแท็บที่เผลอปิดกลับมา
Bookmark (ที่คั่นหน้า)เก็บเว็บที่ใช้บ่อย Ctrl+D · จัดเป็นโฟลเดอร์ “เรียน” “งาน”
Profile (โปรไฟล์)แยกบัญชีส่วนตัวกับบัญชีมหาวิทยาลัยคนละโปรไฟล์ ไม่ปนกัน
Incognito / InPrivateไม่จำประวัติในเครื่อง เหมาะกับเครื่องสาธารณะ แต่ ไม่ได้ซ่อนตัวจากเว็บหรือเครือข่าย
Extension (ส่วนขยาย)เพิ่มความสามารถ เช่น บล็อกโฆษณา ตรวจคำ — ติดตั้งจากร้านค้าทางการเท่านั้น และติดเท่าที่จำเป็น
เปิด Settings ของ Browser ที่ใช้ แล้วหาเมนูต่อไปนี้ให้เจอ
  1. เบราว์เซอร์อัปเดตล่าสุดหรือยัง
  2. เว็บไหนขอสิทธิ์ใช้กล้อง/ไมค์/ตำแหน่ง/การแจ้งเตือนไว้บ้าง
  3. มีรหัสผ่านที่บันทึกไว้และถูกแจ้งว่ารั่วไหลหรือไม่
  4. ลบ Cookies และ Cache ของเว็บเดียว
อัปเดตChrome: ⋮ → Help → About Google Chrome · Edge: ⋯ → Help and feedback → About Microsoft Edge สิทธิ์ของเว็บSettings → Privacy and security → Site settings — ปิดการแจ้งเตือนจากเว็บแปลก ๆ (ตัวการโฆษณาเด้งบ่อยที่สุด) รหัสผ่านChrome: Google Password Manager → Checkup จะบอกรหัสที่รั่ว ซ้ำ หรืออ่อน ลบเฉพาะเว็บกดไอคอนหน้า URL → Site settings / Cookies and site data → Delete data

ชื่อเมนูอาจต่างกันเล็กน้อยตามเวอร์ชัน ใช้ช่องค้นหาในหน้า Settings ช่วยได้
🍪 Cookies กับ Cache ต่างกันยังไง
Cookiesข้อมูลเล็ก ๆ ที่เว็บฝากไว้ เช่น สถานะ login ตะกร้าสินค้า ภาษา · บางชนิดใช้ติดตามพฤติกรรมเพื่อยิงโฆษณา Cacheสำเนารูปและไฟล์ของเว็บ ทำให้เปิดซ้ำเร็วขึ้น · ถ้าเว็บแสดงผลแปลก ๆ ลองล้าง Cache

แก้ปัญหาเบื้องต้นด้วยตัวเอง

  1. อ่านข้อความ error ให้จบ — ส่วนใหญ่บอกสาเหตุไว้แล้ว แคปหน้าจอเก็บไว้ถามคนอื่นได้
  2. รีเฟรช / ปิดแล้วเปิดใหม่ — F5 หรือ Ctrl+F5 (รีเฟรชแบบไม่ใช้ Cache)
  3. เช็กเน็ต — เปิดเว็บอื่นได้ไหม สลับ Wi-Fi/4G ดู
  4. ลองเบราว์เซอร์อื่นหรือ Incognito — ถ้าได้ แปลว่าปัญหาอยู่ที่ Extension หรือ Cache
  5. รีสตาร์ตเครื่อง — แก้ได้มากกว่าที่คิด
  6. ค้นหาข้อความ error — คัดลอกไปค้นใน Google หรือถาม AI พร้อมบอกว่าใช้เครื่องอะไร

ข้อใดถูกต้องเกี่ยวกับโหมด Incognito?

Incognito แค่ “ไม่จำ” ในเครื่องเรา แต่เว็บไซต์ ผู้ให้บริการเน็ต และผู้ดูแลเครือข่าย (เช่น Wi-Fi มหาวิทยาลัย) ยังเห็นการใช้งานได้ตามปกติ
